AI Foundations for Managers

Move with Sam Rosa

Calendar-aware Pilates booking with human approval.

The problem

Clients email back and forth to find an opening. Sam checks the calendar manually and decides whether to confirm.

The product

A branded Pilates site with a browsable calendar, Private/Group lesson selection, booking review, and testimonials.

How the system works

Client → Booking Concierge Agent → Google free/busy → Gmail review request → Human approval → Calendar event

The agent

Extracts structured intent, validates lesson type, refuses prompt injection, and never writes to the calendar directly.

Demo

Browse a date → choose a time → submit a request → receive an approval email.

Cost

Current deterministic operations use zero LLM tokens. The agent path uses the course model and requires measured usage logging.

Safety

Human approval before calendar writes. Tool allowlist. Structured validation. Prompt-injection refusal tests.

Impact

One place for a client to understand the practice, find an opening, and request a lesson.

Next

Public HTTPS deployment, real-user pilot, measured token economics, screenshot evidence, and production data storage.
