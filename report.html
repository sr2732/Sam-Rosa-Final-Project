1. Motivation

Sam’s original Carrd site communicates her training, teaching philosophy, photos, locations, and client stories, but it does not let a prospective client see openings or request a lesson in a structured way. Today, a client must find the contact link, write an email, suggest a time, and wait. Sam must read each request, check her calendar, reply, and decide whether to add an appointment.

The app addresses this friction for beginners, athletes, and clients from non-traditional Pilates backgrounds while preserving Sam’s approval control.

No timed real-user pilot has been completed, so this report does not claim measured hours saved.

2. What is new here

Calendly, Acuity, Google Appointment Schedules, Microsoft Bookings, and generic forms already solve parts of this problem. This project is not novel merely because it has a calendar.

Its difference is the combination of Sam’s original brand and content, Google free/busy as the source of truth, a browsable calendar, Private/Group lesson selection, a reviewable booking email, approval/rejection links, and an in-site testimonial flow.

It is a focused integration for one instructor, not a replacement for mature scheduling software with payments, recurring appointments, and cancellation policies.

4. Models and a real run

No language model is currently called, so there is no truthful model-choice claim. The verified local run is: Google OAuth completed; status returned connected; availability returned Google free/busy data; the client browsed a month, selected a date and time, and submitted a structured request; the backend sent an ASCII-safe subject, “Pilates booking request - Client Name,” and included approval/rejection links.

Screenshots are still required: homepage, calendar selection, booking email, approval, testimonial submission, and a safety test.

7. Impact

The app makes it possible for a client to browse dates, choose Private or Group, submit a structured request, and leave a testimonial. Sam receives a reviewable request instead of an unstructured message.
